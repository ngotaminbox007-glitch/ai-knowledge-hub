How scores work

  • All scores are 0-100. With the checkbox on, each score is the average of the measured value and the AI Hub rating: (measured + hub) / 2.
  • Multi-file refactor / Bug-fix success: % of agent PRs merged for that task type.
  • API integration speed: 100 × (1 − ln(hours to PR close / 0.5) / ln(48)). 30 min scores 100, 24 h scores 0.
  • Latency: community estimate of time to a first usable result.
  • Cost / merged task: 100 × (1 − ln(cost / $0.25) / ln(100)). $0.25 scores 100, $25 scores 0.
  • Capability score: weighted average of Refactor, Bug fix, API speed and Latency using the sliders, normalized by the sum of the weights.
  • ROI multiple: (hours saved × rate) / (cost + (review min / 60 × rate) / merge rate). Value per dollar spent, including review of PRs that never merge.
  • ROI score: min(100, ROI multiple × 25).
  • Break-even review min: max(0, (hours × rate − cost) × merge × 60 / rate). Review minutes per PR at which ROI drops to 1.0×. Higher is better.
  • Badges show confidence in the underlying data: High, Medium or Low. Green cells mark the best value in each column. Hub labels: ≥90 V.High, ≥75 High, ≥55 Med, ≥35 Low.
