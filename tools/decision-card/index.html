Before you ask

  • Show the exact action.

    Include the final wording or file, the destination, the cost and when it would happen.

  • Make one decision easy.

    Show up to five choices, mark the one you recommend and allow a typed reply.

  • Keep proof private.

    Point to the evidence in the existing private record. Copying a card does not approve or send it.

Choose a skill for the task

Read the approved request first. Use the most specific skill available for each distinct part of the task. If it is unavailable, use an approved fallback or state what is blocked.

  • Claims or comparisons

    Use the research skill that fits. Record the source and date, separate observation from inference, and mark missing coverage.

  • Documents or data

    Use the format-specific reader. Compare exports read-only and keep record values in the approved private system.

  • Code or design

    Match the existing stack. Use the relevant design or documentation skill and verify on safe sample data.

  • Actions outside the draft

    A skill is not permission. Before any upload, installation, message, schedule, purchase, or release, show the exact item, destination, and cost and wait for approval.
