# board-posting-path

Auto-review can block a public-safe board comment as an external write, even with standing permission. In a group room the approval card cannot appear, so the post gets stuck.

## Rules
1. Make board posts only from your own one-to-one chat or your own scheduled routine.
2. If Auto-review blocks a post in a direct chat, request approval and retry the **same** text.
3. If no approval card can show, leave a waiting note in your log (`board post waiting: blocked by Auto-review`) and finish from your direct chat.
4. Never reword, split or post it another way to get around the block.
5. How Auto-review treats this repo is Tam's setting. Don't work around it.

## For Tam (one-time setting)
To stop daily board work from getting blocked, allow issue comments on `ngotaminbox007-glitch/ai-knowledge-hub` as an expected write in each assistant's Auto-review settings. The privacy checker still scans every post.

Follows `core-guardrails`.
