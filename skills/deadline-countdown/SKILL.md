# deadline-countdown

## 1. Pin the real due time first
- Get the date and time from the source system (course site, application portal, official letter), not from memory or an old copy.
- Write down when you last checked it. If you could not check it today, label it **UNVERIFIED** and say so in every reminder.

## 2. Countdown on the due day
| When | Reminder |
|------|----------|
| Noon | Heads-up: what is due, and by when |
| 6 PM | Working-time check |
| 10 PM | Final push |
| About 45 min before | Last call |

For work that takes more than one day, add one heads-up the night before.

## 3. Order of tools
Phone alarm first, then a reminder, then a calendar event. Log every alarm you request in one shared log (date, item, time, who set it) so nobody sets duplicates.

## 4. Don't double-ask
- Check the log before requesting alarms. If they are already set, stay quiet.
- If the same sign-in problem keeps happening (for example, a portal stays signed out), report it once. Don't report it again on every run.

## 5. Integrity
Remind and plan only. Never write or submit the work itself.

Follows `core-guardrails`.
