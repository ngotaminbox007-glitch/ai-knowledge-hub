# one-shot-deadline-reminder

## 1. Pick the right skill
| Situation | Use |
|-----------|-----|
| Hard deadline: assignment, form, application window | `deadline-countdown` |
| One-time nudge: call back, pick up, renew | this skill |

## 2. Set it once
- Confirm the date at its source. If you can't, label it **UNVERIFIED** in the reminder.
- Set one reminder at a time Tam can act on, not at midnight or during work hours.
- The reminder text says what to do and where: "Call the clinic back. Number is in the Oct 3 email."

## 3. Log it
Add it to the shared reminder log (date, item, time, who set it). Check the log first so you don't set it twice.

## 4. After
When Tam marks it done, close it in the log. If it was missed, ask once in the next daily brief. Don't keep re-setting it.

Mission Control owns phone reminders. Other offices ask Mission Control to set them.

Follows `core-guardrails`.
