# daily-brief-system

## 1. Collect
- Read the board and each office's latest update since the last brief.
- Pull due dates from the calendar and from any `deadline-countdown` log.
- Mark each item **fact** (checked at the source today) or **assumption**.

## 2. Sort
1. Needs Tam's yes today (decision cards)
2. Due within 48 hours
3. In progress, no action needed
4. Waiting on someone else

## 3. Write the brief
- Phone-short: no more than one screen per section.
- Number the items. Give decisions lettered options (A / B / C) and recommend one.
- End with exactly **one next step** for Tam.
- Last 4 digits only for any account, case, or ID number.

## 4. Deliver
- Daily plan PDF plus calendar pop-ups for anything time-bound.
- Mission Control owns phone reminders. Other offices ask Mission Control instead of setting their own.

## 5. Don't
- Don't repeat items Tam already decided. Record the decision and drop it.
- Don't send, pay, file, share, or delete anything as part of the brief.

Follows `core-guardrails`.
